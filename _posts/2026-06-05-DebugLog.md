## 용도
Editor의 OutLog 창에 log를 띄우기 위한 기능

## 로그 수준

| 이름    | 출력                            |
| ------- | ------------------------------- |
| Log     | 로그 파일 출력/에디터 로고 출력 |
| Display | 일반 로그 출력                  |
| Warning | 경고 로그 출력                  |
| Error   | 에러 로그 출력                  |

## 사용법
```
UE_LOG(LogTemp,Log,TEXT("A"))
UE_LOG(로그 카테고리,로그 수준,출력 텍스트)
```

## 로그 카테고리 추가

```
// .h 에서 선언
DECLARE_LOG_CATEGORY_EXTERN(CustomLog,Log,All);
DECLARE_LOG_CATEGORY_EXTERN(카테고리 이름,로스 수준, 빌드 후 출력할 수준);

// .cpp 에서 매크로 작성
DEFINE_LOG_CATEGORY(CustomLog);

```
